Playlists

Save Main saves the Main Queue. Save A / Save B save the song on that deck plus everything in its queue, in order.

    Add from YouTube

    Paste links from YouTube or YouTube Music: songs, playlists or albums, one per line. In YouTube Music, use ⋮ → Share → Copy link. You can also drag a link onto a queue, or press Ctrl+V anywhere in DJ Dudes.

    YouTube songs need the internet while they play and may show ads. Some songs can't be played outside YouTube; DJ Dudes skips those. Fades, automix and the phone remote work, but EQ and pitch don't (YouTube doesn't let other apps change its sound).

    YouTube songs only work in the desktop app. Close this page and start DJ Dudes with Start DJ Dudes.bat.

    📱 Phone remote

    1. Connect your phone to the same Wi-Fi as this PC.
    2. Point the phone's camera at the code and open the link (or type the address below into the phone's browser).
    3. If Windows asks, allow DJ Dudes on Private networks.

    The phone remote needs the desktop app (npm start). A page opened straight from a file in a web browser isn't allowed to accept connections from your phone.
